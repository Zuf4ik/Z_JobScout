# Обновлённый интерфейс JobScout

Это готовая замена папки `web` для репозитория `Z_JobScout` в ветке `feature/web-platform`.

## Возможности
- Страницы «Обзор», «Вакансии», «Избранное», «Отклики», «Настройки».
- Реальный поиск через существующий Go REST API `GET /api/v1/vacancies`.
- Поиск по ключевым словам и ограничение опыта, сортировка, фильтр по региону и опция «с зарплатой» (последние два фильтра применяются к уже загруженному набору).
- Подробности вакансии и переход на сайт источника.
- Локальное избранное, заметки и статусы откликов (localStorage браузера).
- Адаптивное оформление для телефона и компьютера.

## Установка в существующий проект
1. Скопировать содержимое архива **в папку `web/`** проекта, заменяя одноимённые файлы. Не трогать папку с Go backend.
2. Из PowerShell в `E:\ПРОЕКТЫ\JobScout\web` выполнить `npm install`.
3. В одном терминале из корня проекта запустить `go run ./cmd/api`.
4. В другом, из папки `web`, выполнить `npm run dev`.
5. Проверить `npm run build`.

Если `npm install` из-за конфликтующих версий уже существовавшего проекта завершается ошибкой, сначала проверить `node -v`, затем удалить **только** `web/node_modules` и `web/package-lock.json` и повторить `npm install`. Не удалять исходники.

## Ограничения MVP
- Нет настоящей авторизации, серверного хранения избранного и истории откликов — они сохраняются только в текущем браузере.
- Статус «Откликнулся» отмечает пользователь; JobScout пока не отправляет отклики работодателям.
- ИИ-анализ, рассылка резюме, автоматическое обновление по расписанию и PostgreSQL пока не подключены.
- REST API получает ограниченную выборку с первой страницы источника; клиентские фильтры работают только по ней.
- Профиль здесь служит для персональных настроек интерфейса, он не отправляется работодателям.
