# JobScout

Персональный помощник для поиска вакансий.
Проект разрабатывается на Go.

Цель — собирать вакансии из нескольких источников,
отбирать подходящие и показывать их через Telegram.

## Текущее состояние

Работает консольный прототип:

- Чтение вакансий из JSON-файла.
- Поиск по названию и описанию без учёта регистра.
- Передача поискового запроса через аргумент запуска.
- Проверка отсутствующего и пустого запроса.

В демонстрационном режиме используются вымышленные вакансии.
Интернет для запуска не требуется.

## Требования

Установленный Go версии, указанной в файле go.mod, или новее.

## Запуск

Склонируйте репозиторий и перейдите в папку проекта:

```bash
git clone https://github.com/Zuf4ik/Z_JobScout.git
cd Z_JobScout
```

Запустите поиск:

```bash
go run . Golang
```

Другие примеры:

```bash
go run . Python
go run . Java
```

Поиск выполняется в файле examples/vacancies.json.
Для Golang и Python ожидаются два результата, для Java — ноль.

## План развития

- Подключение проверенных источников вакансий.
- Общий формат данных для разных источников.
- Telegram-бот для поиска и уведомлений.
- PostgreSQL для вакансий, настроек и истории откликов.
- Разбор требований и черновики сопроводительных писем с ИИ.
