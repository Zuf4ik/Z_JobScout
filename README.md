# JobScout

**JobScout** — веб-платформа и Telegram-помощник для поиска вакансий, разрабатываемые на Go, React и PostgreSQL.

Проект предназначен для поиска предложений из разных источников, фильтрации по профессиональным навыкам и опыту, а в перспективе — персонального подбора вакансий с помощью ИИ.

**Статус:** активная разработка (MVP).

## Технологии

**Backend**
- Go
- REST API (`net/http`)
- PostgreSQL 18
- pgx/v5
- Argon2id
- Модульные и интеграционные тесты

**Frontend**
- React
- TypeScript
- Vite
- CSS

**Дополнительно**
- Telegram Bot API
- Git / GitHub
- API «Работа России»

## Реализованный функционал

### Поиск вакансий
- Получение вакансий через API «Работы России».
- Чтение локальных JSON-файлов в поддерживаемых форматах.
- Фильтрация по ключевым словам и требуемому опыту.
- Единая модель вакансий для разных источников.
- Вывод компании, региона, зарплаты и ссылки на вакансию.
- Консольный интерфейс и REST API.

### Веб-интерфейс
- Интерфейс поиска вакансий на React и TypeScript.
- Карточки вакансий и фильтры.
- Адаптивная вёрстка.
- Избранное и отслеживание откликов в локальном хранилище браузера.
- Взаимодействие с Go Backend через HTTP API.

### Telegram
- Telegram-бот для поиска вакансий.
- Команда `/search`.
- Интеграция с поисковой логикой JobScout.

### PostgreSQL
- Отдельная база данных `jobscout`.
- Таблицы пользователей, избранных вакансий, откликов и сессий.
- Репозитории `UserRepository`, `FavoriteRepository` и `SessionRepository`.
- Пул соединений через `pgxpool`.

### Авторизация (backend)
- Регистрация пользователей по email и паролю.
- Проверка паролей.
- Хеширование через Argon2id с индивидуальной солью.
- Создание и отзыв пользовательских сессий.
- Хранение SHA-256-хешей токенов в PostgreSQL.
- HTTP-обработчики регистрации и входа.

Авторизация в React и полный набор защищённых HTTP-эндпоинтов находятся в разработке.

## Архитектура

```text
JobScout/
├── cmd/
│   ├── api/             # HTTP-сервер
│   └── dbcheck/         # Проверка PostgreSQL
├── internal/
│   ├── database/        # Подключение к PostgreSQL
│   ├── httpapi/         # HTTP-обработчики
│   ├── provider/        # Источники вакансий
│   ├── repository/      # SQL-запросы
│   ├── search/          # Фильтрация
│   ├── service/         # Бизнес-логика
│   ├── user/            # Модели пользователей и сессий
│   └── vacancy/         # Модели вакансий
├── migrations/          # SQL-миграции
├── web/                 # React + TypeScript
├── examples/            # Демонстрационные данные
├── main.go              # CLI и запуск Telegram-бота
└── go.mod
```

Проект использует разделение ответственности между HTTP-обработчиками, сервисами, репозиториями и моделями.

## Локальный запуск

### Требования

- Go — совместимая версия, указанная в `go.mod`
- Node.js и npm
- PostgreSQL
- Git

### 1. Клонирование

```bash
git clone https://github.com/Zuf4ik/Z_JobScout.git
cd Z_JobScout
```

Для версии с веб-интерфейсом и PostgreSQL используйте ветку `feature/web-platform`, пока изменения не объединены с `main`.

### 2. Конфигурация

Создайте `.env` в корне проекта на основе `.env.example`.

Для подключения PostgreSQL необходима переменная:

```dotenv
DATABASE_URL=postgres://jobscout_user:CHANGE_ME@localhost:5432/jobscout?sslmode=disable
```

Создайте базу данных и примените SQL-миграции из каталога `migrations` в правильном порядке.

**Не публикуйте `.env`, пароли и токены доступа в GitHub.**

### 3. Запуск Go API

```bash
go run ./cmd/api
```

Локальный адрес:

```text
http://127.0.0.1:8080
```

### 4. Запуск React

```bash
cd web
npm install
npm run dev
```

Откройте адрес, который выведет Vite.

### 5. Консольный поиск

Поиск в демонстрационных данных:

```bash
go run . -query Golang
```

Поиск через API «Работа России»:

```bash
go run . -query Golang -source trudvsem-online
```

Фильтрация по опыту:

```bash
go run . -query Golang -source trudvsem-online -max-experience 1
```

## REST API

| Метод | Эндпоинт | Назначение |
|---|---|---|
| GET | `/health` | Проверка состояния API |
| GET | `/api/v1/vacancies` | Поиск вакансий |
| POST | `/api/v1/auth/register` | Регистрация |
| POST | `/api/v1/auth/login` | Вход |

Пример поиска:

```text
GET /api/v1/vacancies?query=Golang&max_experience=1
```

В текущей версии HTTP API авторизации доступен только для локальной разработки.

## Тестирование

Запуск всех Go-тестов:

```bash
go test ./...
```

Проверка компиляции:

```bash
go build ./...
```

Production-сборка frontend:

```bash
cd web
npm run build
```

Тестами покрыты фильтрация и обработка вакансий, работа репозитория избранного, хеширование паролей, регистрация, вход и логика управления сессиями.

Интеграционные тесты PostgreSQL требуют подготовленной базы и соответствующего окружения.

## Ограничения текущей версии

- Поиск через внешний API ограничен возможностями источника.
- Избранное и статусы откликов в React пока сохраняются локально.
- Авторизация не интегрирована с веб-интерфейсом.
- Серверную авторизацию необходимо дополнить защитой от CSRF, ограничением попыток входа и полноценной обработкой сессий.
- Полноценное ИИ-сопоставление резюме и вакансий ещё не реализовано.
- Проект находится в стадии разработки и не подготовлен к публичному production-развёртыванию.
