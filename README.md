# JobScout

Помощник для поиска вакансий, написанный на Go.

Цель проекта — собирать вакансии из нескольких источников,
отбирать их по условиям пользователя и показывать через Telegram.

Сейчас реализовано консольное приложение.
Telegram-бот, PostgreSQL и ИИ пока не подключены.

## Что уже работает

- Получение вакансий через API «Работы России».
- Чтение вакансий из локальных JSON-файлов.
- Преобразование данных источника в общую структуру вакансии.
- Поиск по названию и описанию без учёта регистра.
- Фильтрация по максимальному требуемому опыту.
- Вывод компании, региона, зарплаты, опыта и ссылки.
- Именованные параметры запуска и встроенная справка.
- Автоматические тесты фильтрации и разбора опыта.

## Требования

Установленный Go версии, указанной в go.mod, или новее.

Для сетевого поиска нужен доступ к API «Работы России».
Учебный пример работает без интернета.

## Установка

```bash
git clone https://github.com/Zuf4ik/Z_JobScout.git
cd Z_JobScout
```

Все команды ниже выполняются из корня проекта.

## Быстрый запуск

Поиск в учебных данных:

```bash
go run . -query Golang
```

Учебный файл examples/vacancies.json содержит три вымышленные
вакансии. По запросу Golang ожидаются два результата.

Получение реальных вакансий из API:

```bash
go run . -query Golang -source trudvsem-online
```

Поиск с ограничением требуемого опыта до одного года включительно:

```bash
go run . -query Golang -source trudvsem-online -max-experience 1
```

Справка:

```bash
go run . -h
```

## Параметры запуска

| Параметр | Назначение | По умолчанию |
|---|---|---|
| -query | Непустой поисковый запрос | Нужно указать |
| -source | Способ получения и формат данных | remotive |
| -file | Путь к JSON-файлу | examples/vacancies.json |
| -max-experience | Максимальный требуемый опыт, лет | -1 — без ограничения |

Варианты -source:

- remotive — чтение локального JSON в формате Remotive.
  Этот формат используется и учебным файлом.
- trudvsem — чтение сохранённого JSON «Работы России».
- trudvsem-online — получение вакансий через API «Работы России».

В сетевом режиме параметр -file не используется.

Запрос из нескольких слов заключайте в кавычки:

```bash
go run . -query "Backend Developer"
```

Поиск проверяет целую переданную подстроку.

## Работа с сохранёнными ответами

Если у вас уже есть файл ответа «Работы России»:

```bash
go run . -query Golang -source trudvsem -file trudvsem-response.json
```

Для сохранённого ответа Remotive:

```bash
go run . -query Python -source remotive -file remotive-response.json
```

Эти скачанные файлы не входят в репозиторий.
Для демонстрационного запуска достаточно examples/vacancies.json.

## Правила фильтрации по опыту

Без параметра -max-experience ограничение не применяется.

При значении 1:

- Вакансии с опытом 0 или 1 год сохраняются.
- Вакансии с опытом больше одного года исключаются.
- Вакансии без указанного опыта сохраняются с соответствующей пометкой.

Значение -1 отключает ограничение.
Значения меньше -1 и нецелые числа не допускаются.

Отсутствующий опыт не считается нулевым.

## Как устроена обработка

1. Программа разбирает параметры запуска.
2. Загружает данные из выбранного источника.
3. Преобразует их в срез структур Vacancy.
4. Применяет текстовый фильтр.
5. При необходимости применяет фильтр опыта.
6. Выводит оставшиеся вакансии.

Чтение файла, получение данных из API, разбор JSON
и фильтрация разделены на функции.

## Проверки

Запуск всех тестов:

```bash
go test -v ./...
```

Тесты проверяют:

- Поиск в описании без учёта регистра.
- Отсутствие совпадений.
- Фильтрацию по опыту, включая неизвестное значение.
- Различие между отсутствующим опытом, нулём и указанным числом лет.

Тесты используют подготовленные данные и не требуют интернета.
Доступность внешнего API ими пока не проверяется.

## Текущие ограничения

- Сетевой поиск получает только первую страницу — до 20 вакансий.
- Периодический сбор и уведомления пока не реализованы.
- Совпадение по слову не означает соответствие профессии
  или всем требованиям.
- Фильтр опыта использует числовое поле источника
  и не проверяет противоречия с описанием.
- Дополнительные условия, включая квотируемые рабочие места,
  пока не отображаются в карточке.
- Зарплата выводится текстом; фильтрации по сумме пока нет.
- Работа с идентификаторами разных источников ещё не унифицирована.

## Источники

[Работа России](https://trudvsem.ru) — реализован сетевой поиск.

Remotive — реализовано чтение сохранённого ответа.
При пробном обращении ответ не соответствовал параметрам фильтрации;
причина пока не установлена.

Подключение hh.ru для сценария проекта не настроено.
